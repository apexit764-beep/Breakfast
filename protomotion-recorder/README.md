# Figma Prototype Recorder

سكربت بيفتح رابط بروتوتايب Figma في متصفح، بيشغّله، وبيسجّله فيديو.

## التنصيب (مرة وحدة)

محتاج [Node.js](https://nodejs.org) مثبّت على الجهاز.

افتح PowerShell جوّا مجلد `protomotion-recorder` وشغّل:

```
npm install
npx playwright install chromium
```

## الاستخدام

```
node record.js -u "رابط_البروتوتايب"
```

الفيديو بينحفظ باسم `prototype.webm` في نفس المجلد.

## الخيارات

| الخيار | الوصف | الافتراضي |
|---|---|---|
| `-u, --url` | رابط بروتوتايب Figma (مطلوب) | — |
| `-o, --output` | مسار ملف الإخراج | `prototype.webm` |
| `-m, --maxdur` | أقصى مدة تسجيل بالثواني | `120` |
| `-i, --idle` | يوقف بعد هالثواني من عدم التغيّر | `5` |
| `-p, --pause` | ثواني بين كل ضغطة تلقائية | `2` |
| `-w, --width` | عرض الشاشة | `1536` |
| `-h, --height` | ارتفاع الشاشة | `864` |
| `-s, --scale` | معامل دقة الشاشة | `1` |
| `--manual` | إنت بتضغط بنفسك، السكربت بيسجّل بس | مطفي |
| `--headless` | تشغيل بدون متصفح ظاهر | مطفي |
| `--debug` | يطبع تغيّرات حجم/zoom الـ canvas | مطفي |
| `--nodetect` | يوقف الـ screenshots (بدون توقف تلقائي) | مطفي |
| `--fps` | عدد الفريمات بالثانية | `60` |
| `--bitrate` | جودة الفيديو بالميغابت/ثانية | `8` |
| `--scaling` | طريقة العرض في Figma | `contain` |
| `--cursor` | يظهر مؤشر الماوس (تحتاجه مع `--manual`) | مطفي |
| `--fit` | يصغّر الشباك تلقائياً عشان يسع في شاشتك | مطفي |
| `--save-clicks` | يحفظ ضغطاتك في ملف JSON | — |
| `--play-clicks` | يعيد الضغطات من ملف JSON | — |

اضغط **Enter** بأي لحظة عشان توقف التسجيل وتحفظه.

## أمثلة

```
node record.js -u "https://figma.com/proto/..."
node record.js -u "https://figma.com/proto/..." --manual
node record.js -u "https://figma.com/proto/..." --nodetect
node record.js -u "https://figma.com/proto/..." --debug
node record.js -u "https://figma.com/proto/..." -p 3 -w 1440 -h 900
```

## ⚠️ الأهم: خلّي الـ viewport نفس مقاس الفريم

هاي أهم قاعدة في السكربت كله. إذا مقاس الشاشة (`-w` و `-h`) ما كان نفس مقاس
الفريم في Figma، رح يصير واحد من اتنين: **قص** من الفيديو، أو **حواف سودا**،
أو **تكبير/تصغير لحظي** أثناء الانتقالات.

لما يكونوا نفس المقاس، Figma ما بيحتاج يكبّر ولا يصغّر أصلاً → صورة نظيفة 1:1.

**كيف تعرف مقاس الفريم؟** في Figma اضغط على الفريم، والمقاس بيبين في اللوحة اليمين (W و H).

| نوع التصميم | الأمر |
|---|---|
| iPhone 16 (393×852) | `node record.js -u "الرابط" -w 393 -h 852 -s 3` |
| iPhone 14 (390×844) | `node record.js -u "الرابط" -w 390 -h 844 -s 3` |
| موبايل (375×812) | `node record.js -u "الرابط" -w 375 -h 812 -s 3` |
| ديسكتوب (1440×1024) | `node record.js -u "الرابط" -w 1440 -h 1024 -s 1` |

**`-s 1` هو الافتراضي، وبيعطيك الحجم الطبيعي** — يعني فيديو بنفس مقاس الفريم بالظبط.
هاد اللي بدك إياه في أغلب الحالات.

`-s 3` بيخلي الدقة ٣ أضعاف (393×852 بتصير 1180×2556) لو بدك جودة أعلى للمونتاج.
بس انتبه: الشباك بيصير أطول من شاشتك وما بتقدر تشوف البروتوتايب كامل — استخدمه
مع `--headless` أو مع `--play-clicks`.

(الأرقام بتنضبط لأقرب عدد زوجي لأن ترميز الفيديو ما بيقبل أبعاد فردية.)

للتصاميم الطويلة اللي بتسكرول: حط `-h` نفس ارتفاع الفريم مش ارتفاع الشاشة.

## الضغط اليدوي على أزرار البروتوتايب

`-s 3` بيخلي الـ viewport أكبر من شاشتك، فالمتصفح بيعرض جزء منه بس. التسجيل
بيطلع سليم، بس ما بتقدر تشوف وين بتضغط.

للضغط اليدوي استخدم `-s 1` مع `--cursor`:

```
node record.js -u "الرابط" -w 393 -h 852 -s 1 --manual --cursor --nodetect
```

هيك بيفتح شباك 393×852 — بيسع في شاشتك كاملاً، وبتشوف المؤشر وبتضغط عادي.

## اضغط بشاشة صغيرة، سجّل بدقة عالية (مرّتين)

شاشتك ما بتسع شباك طوله 2556 — بس ما في داعي تشوف الشباك أصلاً وقت التسجيل النهائي.
الفكرة: تضغط مرة بحجم صغير ومريح، والسكربت بيحفظ ضغطاتك، وبعدين بيعيدها لحاله
بدقة عالية بدون متصفح ظاهر.

**الجولة الأولى — إنت بتضغط:**

```
node record.js -u "الرابط" -w 393 -h 852 --fit --manual --cursor --nodetect --save-clicks clicks.json
```

`--fit` بيقيس شاشتك ويصغّر الشباك لحاله عشان تشوف البروتوتايب كامل من فوق لتحت.
بتشوف المؤشر وبتضغط على أي زر. لما تخلص اضغط Enter.

**الجولة التانية — بيعيدها بدقة عالية:**

```
node record.js -u "الرابط" -w 393 -h 852 -s 3 --headless --nodetect --play-clicks clicks.json
```

بدون متصفح ظاهر (`--headless`) — يعني مقاس شاشتك ما عاد له دخل. الضغطات بتنعاد
بنفس الأماكن وبنفس التوقيت بالظبط، والفيديو بيطلع **1179×2556**.

الضغطات بتنحفظ كنِسَب مئوية من الشاشة مش بكسلات، عشان هيك بتشتغل بأي `-s`.

## نعومة الفيديو

Playwright بيسجّل افتراضياً بـ **25 فريم/ثانية** و **1 ميغابت/ثانية**، والرقمين مثبّتين
في كوده وما في خيار رسمي لتغييرهم. السكربت بيعدّلهم تلقائياً قبل ما يشغّل المتصفح
(افتراضياً 60fps و 8Mbps).

للحصول على أنعم نتيجة:

```
node record.js -u "الرابط" --nodetect --fps 60 --bitrate 12
```

`--nodetect` مهم للنعومة، لأن الـ screenshots اللي بيستخدمها الكشف التلقائي
بتجبر المتصفح يرسم من جديد وبتعمل تقطيع خفيف في التسجيل.

ملاحظة: إذا شغّلت `npm install` من جديد، بترجع إعدادات Playwright الأصلية —
بس السكربت بيعدّلها تلقائياً في كل تشغيل، فما بتحتاج تعمل إشي.

### تحويل لـ MP4 للمونتاج

```
ffmpeg -i prototype.webm -c:v libx264 -crf 16 -preset slow -pix_fmt yuv420p prototype.mp4
```

## تشخيص مشكلة الـ zoom blink

إذا الفيديو فيه تكبير/تصغير لحظي أثناء الانتقال بين الشاشات:

1. شغّل بـ `--nodetect`. إذا اختفت المشكلة → السبب كان الـ screenshots بتشوش على تسجيل الفيديو.
2. إذا ضلّت، شغّل بـ `--debug` وشوف شو بيتغيّر:
   - `buffer` أو `css` بيتغير → حجم عنصر الـ canvas بيتغير.
   - `transform` بيتغير → Figma بيغيّر الـ zoom.
   - ما في تغيّر → المشكلة جوّا WebGL، وبتنحل من إعدادات الانتقال في Figma.
3. جرّب تغيّر نوع الانتقال في Figma لـ **Instant** أو **Dissolve** بدل Move In / Slide In / Push.

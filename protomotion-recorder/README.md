# Figma Prototype Recorder

سكربت بيفتح رابط بروتوتايب Figma في متصفح، بيشغّله، وبيسجّله فيديو.

## التنصيب (مرة وحدة)

محتاج [Node.js](https://nodejs.org) مثبّت على الجهاز.

افتح PowerShell جوّا مجلد `protomotion-recorder` وشغّل:

```
npm install
npx playwright install chromium
```

## الاستخدام

```
node record.js -u "رابط_البروتوتايب"
```

الفيديو بينحفظ باسم `prototype.webm` في نفس المجلد.

**التسجيل بيوقف لما تضغط Enter.** ما في توقف تلقائي — السكربت ما بياخد أي screenshots أثناء التصوير عشان ما يشوّش على الفيديو. في بس حد أقصى للأمان (`-m`، افتراضياً 10 دقايق) عشان ما يضل يسجّل لو نسيته شغّال.

## الخيارات

| الخيار | الوصف | الافتراضي |
|---|---|---|
| `-u, --url` | رابط بروتوتايب Figma (مطلوب) | — |
| `-o, --output` | مسار ملف الإخراج | `prototype.webm` |
| `-m, --maxdur` | حد أقصى لمدة التسجيل بالثواني (أمان) | `600` |
| `-p, --pause` | ثواني بين كل ضغطة تلقائية | `2` |
| `-w, --width` | عرض التصوير | `1536` |
| `-h, --height` | ارتفاع التصوير (بينتجاهل إذا استعملت `-a`) | `864` |
| `-a, --aspect` | نسبة الأبعاد للفيديو: `16:9`، `4:5`، `1.91:1`، أو رقم مثل `1.78` — الارتفاع بينحسب من `-w` | — |
| `-r, --res` | مقاس ثابت بدل النسبة، مثل `2880x1838` | — |
| `-s, --scale` | كثافة الرسم — بتضرب دقة الفيديو النهائية | `1` |
| `--fit` | كيف بينحط فريم Figma جوّا المقاس: `width` / `screen` / `actual` | `width` |
| `--manual` | إنت بتضغط بنفسك، السكربت بيسجّل بس | مطفي |
| `--headless` | تشغيل بدون متصفح ظاهر | مطفي |
| `--debug` | يطبع تغيّرات حجم/zoom الـ canvas | مطفي |

اضغط **Enter** بأي لحظة عشان توقف التسجيل وتحفظه.

## أمثلة

```
node record.js -u "https://figma.com/proto/..."
node record.js -u "https://figma.com/proto/..." --manual
node record.js -u "https://figma.com/proto/..." --debug
node record.js -u "https://figma.com/proto/..." -p 3 -w 1440 -h 900
node record.js -u "https://figma.com/proto/..." -a 16:9 -w 2880
node record.js -u "https://figma.com/proto/..." -a 4:5 -w 1080 --fit screen
node record.js -u "https://figma.com/proto/..." -r 2880x1838
```

## نسبة الأبعاد والمقاس (Aspect Ratio)

المقاس النهائي للفيديو إنت اللي بتحدده، **مهما كان مقاس الفريم في Figma**.

**بالنسبة (المُوصى فيه):** بتحدد النسبة بـ `-a` والعرض بـ `-w`، والارتفاع بينحسب لحاله:

```
node record.js -u "..." -a 16:9  -w 2880    ->  2880x1620
node record.js -u "..." -a 4:5   -w 1080    ->  1080x1350
node record.js -u "..." -a 1.91:1 -w 1200   ->  1200x628
```

**بمقاس ثابت:** إذا بدك رقم محدد بالظبط:

```
node record.js -u "..." -r 2880x1838        ->  2880x1838
```

**بزيادة الدقة بس:** `-s` بتضرب الدقة النهائية بدون ما تغيّر الشكل أو النسبة:

```
node record.js -u "..." -w 1920 -h 1226 -s 1.5   ->  2880x1840
```

المعادلة: **دقة الفيديو = العرض × الارتفاع × `-s`**. والسكربت بيطبع المقاس والنسبة قبل ما يبدأ التسجيل عشان تتأكد.

### `--fit` — كيف بينحط تصميم Figma جوّا هالمقاس

لما نسبة الفيديو تختلف عن نسبة الفريم في Figma:

| القيمة | شو بتعمل |
|---|---|
| `width` (افتراضي) | بتملا العرض كامل، وممكن يتقصّ من فوق/تحت |
| `screen` | بيبان الفريم كامل، والفاضي بينملا بلون خلفية البروتوتايب |
| `actual` | بدون تصغير/تكبير |

```
node record.js -u "..." -a 9:16 -w 1080 --fit screen
```

**ملاحظات:**
- الأرقام الفردية بتنضبط لأقرب رقم زوجي لأن ترميز الفيديو بيفضّل الأبعاد الزوجية (مثلاً `1839` بتصير `1840`).
- المقاسات الكبيرة (فوق ~3000 بكسل) بتزيد استهلاك المعالج والذاكرة؛ لو التسجيل صار متقطّع، صغّر `-w` أو استعمل `-s 1`.

## تشخيص مشكلة الـ zoom blink

إذا الفيديو فيه تكبير/تصغير لحظي أثناء الانتقال بين الشاشات:

1. الـ screenshots اللي كانت بتشتغل أثناء التصوير (السبب الأول المشتبه فيه) **انشالت من السكربت نهائياً**، فالمفروض تكون المشكلة راحت.
2. إذا ضلّت، شغّل بـ `--debug` وشوف شو بيتغيّر:
   - `buffer` أو `css` بيتغير → حجم عنصر الـ canvas بيتغير.
   - `transform` بيتغير → Figma بيغيّر الـ zoom.
   - ما في تغيّر → المشكلة جوّا WebGL، وبتنحل من إعدادات الانتقال في Figma.
3. جرّب تغيّر نوع الانتقال في Figma لـ **Instant** أو **Dissolve** بدل Move In / Slide In / Push.
